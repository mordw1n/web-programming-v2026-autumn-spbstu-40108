# Лабораторная работа 4

## Задание

Вариант 36. Реализовать класс `User` и систему управления пользователями:

1. Класс `User` с полями: `id` (число), `name` (строка), `friends` (массив id
   друзей). Методы: `addFriend(friendId)`, `removeFriend(friendId)`, геттер
   `friendCount`.
2. Функции обработки коллекций: `groupUsersByFriendCount`, `getUniqueFriends`,
   `findUsersWithFriend`, `findUsersAboveFriendCount`, `findUsersWithoutFriends`.
3. Пользовательский интерфейс: форма добавления пользователя, список карточек
   сущностей с возможностью удаления, асинхронные операции через `setTimeout`,
   сохранение состояния в `localStorage`.

## Реализация

Решение разделено на модель и представление:

- `model.js`: содержит реализацию класса `User` и пять чистых функций для работы
  с коллекцией пользователей. Входные массивы не мутируются.
- `main.js`: управляет состоянием приложения, подписывается на события формы и
  списка карточек, выполняет добавление и удаление пользователей асинхронно с
  задержкой через `setTimeout`, а также синхронизирует состояние с
  `localStorage`.
- `index.html` и `styles.css`: реализуют обязательный контракт элементов:
  - `form[data-testid="entity-form"]` с полями `name="id"` и `name="name"`;
  - контейнер списка `[data-testid="entity-list"]`;
  - карточка пользователя `[data-testid="entity-card"]`;
  - кнопка удаления `[data-testid="delete-entity"]`.

## Запуск

Откройте `index.html` в браузере.
