# Лабораторная работа 2

## Задание

Вариант 36. Написать функцию `reverseWords(str)`, которая принимает строку и
возвращает новую строку, в которой порядок символов в каждом слове изменен на
обратный, но порядок самих слов остается прежним.

Примеры:

- `'Hello world'` -> `'olleH dlrow'`
- `'JavaScript Object Notation'` -> `'tpircSavaJ tcejbO noitatoN'`
- `'a b c'` -> `'a b c'`
- `''` -> `''`

## Реализация

Функция реализована в файле `solution.js` с использованием стандартных методов
JavaScript:

1. Выполняется валидация входного аргумента на принадлежность к типу `string`.
2. Исходная строка разбивается на массив слов методом `split(' ')`.
3. Каждое слово преобразуется в массив символов, разворачивается методом
   `reverse()` и объединяется обратно в слово с помощью `join('')`.
4. Полученный массив перевернутых слов объединяется обратно в строку через
   пробел методом `join(' ')`.

Функция экспортируется как именованный экспорт ESM:

```javascript
export function reverseWords(str) { ... }
```
