# Лабораторная работа 5

## Задание

Вариант 36. Реализовать модальное окно книги (`book-modal`) для книжного
интернет-магазина.

Требования:

- Отобразить список книг в виде каталога карточек (`[data-testid="book-card"]`).
- Каждая карточка должна содержать обложку/иконку, название, автора, краткое
  описание, цену и рейтинг.
- При клике на карточку книги открывать всплывающее модальное окно
  (`[data-testid="book-modal"]`) с развернутой информацией о выбранном издании.
- Модальное окно должно содержать кнопку закрытия
  (`[data-testid="modal-close"]`).
- Поддерживать закрытие модального окна тремя способами:
  1. По клику на кнопку закрытия (`modal-close`).
  2. По клику на затемненный оверлей (backdrop) вокруг диалогового окна.
  3. По нажатию клавиши `Escape` на клавиатуре.
- Управлять состоянием модального окна и выбранной книги через React State
  (`useState`).

## Реализация

Проект реализован на React 18 с использованием сборщика Vite.

- **Архитектура компонентов**:
  - `App`: корневой компонент приложения, монтирующийся в
    `[data-testid="app"]`. Хранит состояние выбранной книги (`selectedBook`) и
    видимости модального окна (`isModalOpen`).
  - `BookCard`: компонент отдельной карточки книги (`[data-testid="book-card"]`),
    доступный для навигации с клавиатуры (поддержка `Enter` и `Space`).
  - `BookModal`: модальное окно (`[data-testid="book-modal"]`).
- **Соответствие CI-контракту**:
  - Модальное окно всегда присутствует в DOM-дереве, но при закрытом состоянии
    скрывается через CSS-класс `.book-modal-hidden` (`display: none`). Это
    удовлетворяет контрактному требованию `visible: false` в Playwright.
  - При клике на карточку книги класс переключается на `.book-modal-visible`
    (`display: flex`), и модальное окно становится видимым.
- **Хуки и эффекты**:
  - Обработчик `Escape` регистрируется через `useEffect` с очисткой
    (`removeEventListener`) при размонтировании.
  - Функция закрытия мемоизирована через `useCallback`.
- **Стилизация**:
  - Стили оформлены в `src/styles.css` в соответствии с правилами Stylelint:
    селекторы только по классам (без ID и без квалификаторов тегов), имена
    классов в `kebab-case`, отсутствие `!important`.

## Запуск

1. Перейдите в каталог лабораторной работы:
   ```bash
   cd spiridonov.mikhail/lab5
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Для сборки production-версии:
   ```bash
   npm run build
   ```
