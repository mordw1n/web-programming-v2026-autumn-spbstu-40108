# Лабораторная работа 3

## Задание

Вариант 36. Реализовать функцию `findMaxSubarraySum(arr, k)`, которая находит
максимальную сумму непрерывного подмассива фиксированной длины `k`.

Примеры:

- `findMaxSubarraySum([1, 4, 2, 10, 2, 3, 1, 0, 20], 4)` -> `24`
- `findMaxSubarraySum([-4, -2, -7], 2)` -> `-6`
- `findMaxSubarraySum([-2, 8, 3], 1)` -> `8`
- `findMaxSubarraySum([2, -1, 4], 3)` -> `5`
- `findMaxSubarraySum([9, 8, -20, 1, 2], 2)` -> `17`

## Реализация

Алгоритм реализован в файле `solution.js` по паттерну «скользящее окно» (Sliding
Window), что обеспечивает оптимальную временную сложность `O(n)`:

1. Проверяются граничные условия: массив должен быть непустым, а `k` —
   положительным числом, не превышающим длину массива.
2. Вычисляется сумма первых `k` элементов — это начальное значение окна.
3. В цикле от индекса `k` до конца массива окно сдвигается на один элемент
   вправо: добавляется новый элемент `arr[i]` и вычитается вышедший из окна
   элемент `arr[i - k]`.
4. Максимальная сумма обновляется при превышении текущего значения.

Функция экспортируется как именованный экспорт ESM:

```javascript
export function findMaxSubarraySum(arr, k) { ... }
```

Для проверки импортируйте функцию `findMaxSubarraySum` из файла `solution.js`.
