# Лабораторная работа 1

## Задание

Вариант 36. Создать таблицу с данными о продажах за месяц. Таблица должна иметь
три столбца — «Продукт», «Продано», «Выручка» и пять рядов с данными. В футере
таблицы необходимо отобразить общую сумму проданных товаров и общую выручку. При
создании таблицы необходимо использовать соответствующие семантические теги —
`<thead>`, `<tbody>`, `<tfoot>` и другие. Фон у четных строк должен быть
светло-серым (`#f2f2f2`), а у нечетных — белым (`#ffffff`). Ряд таблицы при
наведении курсора должен выделяться более темным серым цветом (`#d3d3d3`).

## Реализация

Разметка построена с использованием семантических тегов таблицы: `<table>`,
`<caption>`, `<thead>`, `<tbody>`, `<tfoot>`. Заголовок таблицы содержит 3
столбца (`<th>`) с атрибутом `scope="col"`. Тело таблицы `<tbody>` содержит 5
строк данных о продажах. Итоги выведены в футере `<tfoot>` с атрибутом
`scope="row"` для строки итогов.

Стилизация выполнена в `styles.css`:

- Четные строки стилизованы через селектор `tbody tr:nth-child(even)` цветом
  `#f2f2f2`.
- Нечетные строки стилизованы через селектор `tbody tr:nth-child(odd)` цветом
  `#fff`.
- При наведении курсора строка выделяется цветом `#d3d3d3` через псевдокласс
  `:hover`.
- Границы ячеек объединены через `border-collapse: collapse`.

## Запуск

Откройте `index.html` в браузере.
