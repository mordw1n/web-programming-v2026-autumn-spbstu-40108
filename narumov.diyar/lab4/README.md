# Лабораторная работа 4

## Задание

Вариант 37. Создать класс `ClothingItem` с полями `id` (число), `name` (строка),
`size` (строка: S, M, L, XL) и `colors` (массив доступных цветов). Реализовать
методы `addColor(color)`, `removeColor(color)` и геттер `colorsCount`. Для
массива товаров реализовать функции группировки товаров по размеру, получения
списка всех уникальных цветов, выбора товаров в заданном цвете, группировки
товаров по количеству доступных цветов и выбора товаров, доступных более чем в N
цветах. Реализовать пользовательский интерфейс: список карточек товаров с
названием, размером, списком цветов и количеством цветов; кнопки «Добавить
цвет», «Удалить цвет», «Добавить товар», «Удалить товар»; форму создания товара
(ID, название, размер) и форму добавления цвета. При любых изменениях интерфейс
обновляется автоматически, все операции добавления и удаления выполняются
асинхронно через Promise и `setTimeout()`, а текущий список сохраняется в local
storage.

## Реализация

Решение разделено на модель и интерфейс.

В `model.js` объявлен класс `ClothingItem`. Конструктор проверяет аргументы:
`id` должен быть целым положительным числом, `name` — непустой строкой, `size` —
одним из допустимых размеров, `colors` — массивом. При неверном типе
выбрасывается `TypeError`, при верном типе и недопустимом значении — `Error`.
Массив цветов копируется через spread, чтобы товар не делил его с вызывающим
кодом. Геттер `colorsCount` возвращает длину `colors` и вычисляется при каждом
обращении, поэтому не может разойтись с реальным списком. Метод `addColor`
отказывается добавлять пустую строку и уже существующий цвет, `removeColor`
сообщает об ошибке, если удаляемого цвета нет.

Там же объявлены пять функций работы с коллекцией, каждая из которых начинается
с проверки аргументов. `groupItemsBySize` и `groupItemsByColorCount` возвращают
`Map`, где ключ — размер или количество цветов, а значение — массив товаров.
`getUniqueColors` обходит все товары и собирает цвета без повторов.
`findItemsByColor` и `findItemsAboveColorCount` используют `filter`, поэтому
возвращают новый массив и не изменяют входной.

В `main.js` находится интерфейс. Состояние хранится в массиве `items`, который
при старте читается из local storage и восстанавливается в экземпляры
`ClothingItem`, а при отсутствии или повреждении сохранённых данных заполняется
начальным набором товаров. Обращения к local storage обёрнуты в `try`, потому
что хранилище может быть недоступно, а квота — исчерпана.

Асинхронность реализована функцией `runAsync`: она возвращает `Promise`, внутри
`setTimeout` вызывает переданную операцию в блоке `try` и переводит промис в
состояние fulfilled через `resolve` либо в состояние rejected через `reject`.
Вызывающий код обрабатывает все три состояния: на время ожидания кнопка операции
блокируется и показывается сообщение «Выполняется…», в `then` обновляется
разметка и выводится сообщение об успехе, в `catch` выводится текст ошибки, а в
`finally` кнопка разблокируется. Благодаря этому ошибка модели не теряется
внутри `setTimeout`, а доходит до пользователя, при этом состояние приложения
остаётся прежним. Сообщения выводятся в элемент с `role="status"` под формой.

Проверки, относящиеся к коллекции, выполняются внутри асинхронной операции: при
добавлении проверяется уникальность `id`, при изменении цветов и удалении —
существование товара. Проверка именно внутри операции, а не перед её запуском,
защищает от повторного нажатия, пока предыдущее изменение ещё не применилось.

Разметка карточек строится методами `document.createElement` и `textContent`, а
не через `innerHTML`, чтобы названия товаров и цветов не могли попасть в
документ как разметка. Обработчики событий навешены на контейнер списка, а не на
каждую кнопку: нужный товар определяется по `data-id` ближайшей карточки, а
действие — по `data-testid` и `data-action` нажатого элемента. Такая делегация
позволяет не переподписываться после каждой перерисовки.

Публичный контракт интерфейса: список товаров помечен
`data-testid="entity-list"`, форма создания — `data-testid="entity-form"` с
полями `name="id"`, `name="name"` и `name="size"`, карточка —
`data-testid="entity-card"`, кнопка удаления товара —
`data-testid="delete-entity"`.

Блок «Выборки по коллекции» показывает работу всех пяти функций: уникальные
цвета, количество товаров по размерам и по количеству цветов, а также списки
товаров, отфильтрованных по выбранному цвету и по минимальному количеству
цветов.

## Запуск

Откройте `index.html` в браузере. Страница подключает `main.js` как ES module,
поэтому при открытии напрямую с диска браузер может заблокировать импорт из-за
политики CORS — в этом случае запустите любой локальный сервер в каталоге
работы, например `npx serve`, и откройте выданный адрес.
