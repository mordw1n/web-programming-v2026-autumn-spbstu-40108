# Лабораторная работа 2

## Задание

Вариант 20. Написать функцию rgbToHex, которая преобразует строку вида
rgb(255,0,0) в HEX-формат.

## Реализация

Экспортируется именованная функция rgbToHex(str). Из строки регулярным
выражением извлекаются три числа (R, G, B) и приводятся к Number. Каждое число
переводится в шестнадцатеричную систему toString(16), приводится к верхнему
регистру и дополняется нулём слева до двух символов. Результат склеивается с
префиксом #.

## Запуск

Импортируется именованная функция из solution.js.
