# Лабораторная работа 3

## Задание

Вариант 13

Реализуйте функцию sortByFrequency(arr), которая сортирует элементы массива по
частоте встречаемости.

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

sortByFrequency - частые элементы идут первыми; случаи равной частоты не
проверяются.

мощью цикла создаётся хэш-таблица, в которую записывается, сколько раз каждое
число встретилось в массиве. Создаётся копия входного массива, которая
сортируется с помощью метода sort. При сравнении двух элементов проверяются их
счётчики из хэш-таблицы: чем больше частота у числа, тем выше его приоритет и
тем раньше оно встаёт в массиве. Согласно условию, случаи равной частоты
дополнительно не проверяются.

**Граничные случаи**

1. Пустой масив - метод возвращает пустой массив без ошибок
2. Массив из одного элемента - счётчик зафиксирует частоту равную 1, сортировка
   сразу вернет массив из этого одного элемента
3. Уникальные элементы - массив вернется без сбоев
4. Одинаковые элементы - все элементы остаются на своих местах
5. Массив отрицательных числе - масств вернется без каких-либо сбоев
6. Массив, содержащий строк - массив вернется со сбоем

## Запуск

Импортируйте именованный export из `solution.js` как ES module.

```javascript
import {sortByFrequency} from './solution.js';
console.log(sortByFrequency([]));
console.log(sortByFrequency([2]));
console.log(sortByFrequency([1, 3, 2, 5, 7]));
console.log(sortByFrequency([1, 1, 1, 1, 1, 1, 1, 1]));
console.log(sortByFrequency([2, 3, 2, 4, 5, -1, 12, 2]));
console.log(sortByFrequency([2, 3, 2, 4, 5, 12, 2, 3, 3, 3, 12]));
console.log(sortByFrequency([2, 3, 2, v, 12, a]));
```
