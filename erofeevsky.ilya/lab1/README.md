# Лабораторная работа 1

## Задание

**Вариант 13.**

Создать блок с текстом. Текст может быть любой длины. Необходимо реализовать с
помощью CSS механизм, который будет скрывать текст, если он превышает высоту 100
пикселей или 3 строки. Если текст выходит за пределы указанного лимита, он
должен обрезаться и заменяться многоточием (…). Текст должен иметь шрифт Arial,
размер шрифта – 16px.

## Реализация

**.html**

В центре страницы, находится редактируемый блок, в которое возможно ввести
текст. По мере заполнения диалогова окна путём: либо заполнения полностью, либо
использованием Enter для перевода на новую строку -- оно будет расширяться. При
достижении лимита в 3 строки, в случае последнего слова перед заполнением строки
или использования Enter ставится (...), с помощью визуального ограничения CSS.

**.css**

Основное решение заключалось в использовании contenteditable=true, которое
создает пустую строку, с возожностью её редактирования, и webkit-box, который
создает контейнер, в котором есть возможность в сокращать текст до (...)

## Запуск

Откройте `index.html` в браузере.
